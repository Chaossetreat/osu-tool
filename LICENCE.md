## 🧩 About

**osu! Tool** is a comprehensive desktop helper for osu! featuring an in-game overlay, beatmap and skin management, replay inspection, practice helpers, config editing, and performance HUD widgets.

Based on popular community tools like **osu!lazer plugins**, **StreamCompanion**, and **osu! trainer utilities**.

---

## ✨ Features

### 🎮 Core Tools
- In-Game Overlay — live stats, hit error bar, and UR display
- Beatmap Manager — sort, search, and clean local beatmap library
- Replay Helper — load and inspect saved replays
- Practice Helper — jump to any point and adjust rate
- Config Editor — edit settings without relaunching the game

### 🎨 Skins & Cosmetics
- Skin Manager — install, preview, and swap skin sets
- HUD Widgets — combo, accuracy, and score overlays
- Custom Cursor — swap cursor and trail visuals
- Score Tracker — session summaries and per-map stats

### 🏋️ Practice & Training
- Rate Changer — play maps from 0.5x to 2.0x
- Loop Trainer — repeat any section until mastered
- Aim Analyzer — review cursor path and timing
- Local Leaderboards — track your own best scores
